# Lógica computacional

## Propósito
Practicar algoritmos, operadores lógicos y organización de archivos en GitHub.

## Autor
Alondra Edith Moreno Alba 395441

## Ejercicios
1. Identificar si un número es par o impar.
2. Construir una tabla de verdad de AND.
3. Resolver una condición de aprobación.

## Herramientas
- Pseudocódigo.
- GitHub.

## Lo que aprendí
- Un repositorio sirve para guardar y organizar todos los archivos de un proyecto junto con su historial de cambios.
- Un commit sirve para registrar un cambio con un mensaje que explica qué se hizo.
- Una rama sirve para trabajar en una mejora sin afectar la versión principal (main).
